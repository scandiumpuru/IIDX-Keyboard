# IIDX-Keyboard

PC browser rhythm-game prototype inspired by the 7-key + scratch layout of arcade-style rhythm games.

## Controls
- `Z X C V S D F`: keys 1-7
- `Left Shift`: scratch input
- `Space`: pause / resume

## Run locally
Open `index.html` in a modern desktop browser. No build step or dependencies are required.

## GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for deployment. The site URL is `https://scandiumpuru.github.io/IIDX-Keyboard/`.

## Current prototype scope
- 7-key and scratch keyboard input
- Falling-note playfield and simultaneous inputs
- PGREAT / GREAT / GOOD / BAD / POOR judgments
- EX score, combo, BP, FAST/SLOW counters and a provisional NORMAL gauge
- Demo chart, pause and restart

## Notes
This is an independent fan-made prototype and is not affiliated with or endorsed by KONAMI. It contains no official game assets or music. Judgment windows and gauge behavior are prototype approximations and should be calibrated against documented behavior before claiming exact arcade equivalence.
